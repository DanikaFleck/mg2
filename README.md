## Devlog

There was one error I ran into where I tried to subtract the health by "ONE" which was invalid. In the instructions it says "subtract ONE" which made me think there was a constant ONE declared already. The capitalization threw me off, but it was a very quick fix where I just subtracted by an integer 1.

I think that the period is a pointer that points specifically to the color aspect of the sprite renderer. As far as the 'new' is concerned, I believe it is calling a constructor for a new color variable. I haven't programmed in a long time.
